Learners
########

Open the |person| **Learners** tab from the main |coach| **Coach** dashboard to access the progress report for each learner. In the main view you can see the table with summary of completed exercises, scores and viewed resources **for each learner**, and their last activity. Use the |print| (print) and |download| (download) buttons to print the report for all learners on paper, save it in a PDF format, or export as a CSV file.

#. Click on a learner name to view their detailed progress report.
